## 七、T1 收尾：防火墙放行 8080（浏览器可访问）

- **现象**：VM 内 `curl http://localhost:8080` 正常返回「欢迎使用 RuoYi…」，但宿主机（Windows）浏览器访问 `http://10.0.0.132:8080` 打不开。
- **根因**：CentOS 9 / Rocky 9 默认 firewalld 仅放行了 SSH（22 端口），8080 被拦截；Xshell 能连是因 22 端口已开放。
- **处理**：在 VM 上执行
  ```
  firewall-cmd --zone=public --add-port=8080/tcp --permanent
  firewall-cmd --reload
  ```
- **验收**：从宿主机 `curl http://10.0.0.132:8080` 返回 **HTTP 200**，防火墙 `list-ports` 显示 `8080/tcp`，浏览器可正常访问。
- **说明**：直接打开后端根地址 `http://10.0.0.132:8080` 会显示「请通过前端地址访问」，属正常现象（后端根路径仅返回提示文本）；完整 API 文档在 `/swagger-ui/index.html`。真正的 RuoYi 登录页面需前端 vite 启动后访问。
