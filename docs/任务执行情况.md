## 七、T1 收尾：防火墙放行 8080（浏览器可访问）

- **现象**：VM 内 `curl http://localhost:8080` 正常返回「欢迎使用 RuoYi…」，但宿主机（Windows）浏览器访问 `http://10.0.0.132:8080` 打不开。
- **根因**：CentOS 9 / Rocky 9 默认 firewalld 仅放行了 SSH（22 端口），8080 被拦截；Xshell 能连是因 22 端口已开放。
- **处理**：在 VM 上执行
  ```
  firewall-cmd --zone=public --add-port=8080/tcp --permanent
  firewall-cmd --reload
  ```
- **验收**：从宿主机 `curl http://10.0.0.132:8080` 返回 **HTTP 200**，防火墙 `list-ports` 显示 `8080/tcp`，浏览器可正常访问。
- **说明**：直接打开后端根地址 `http://10.0.0.132:8080` 会显示「请通过前端地址访问」，属正常现象（后端根路径仅返回提示文本）；完整 API 文档在 `/swagger-ui/index.html`。真正的 RuoYi 登录页面需前端 vite 启动后访问。

## 九、T3：设计并落地 6 张业务表（2026-08-15 完成）

### 9.1 建表脚本

- 位置：`/usr/along-trip/sql/create_trip_tables.sql`（已纳入项目仓库，供后续 T4/T5 复用）。
- 执行：`mysql -uroot -p*** --default-character-set=utf8mb4 ry < create_trip_tables.sql`。

### 9.2 落地结果（6 张表）

| 表 | 说明 | 关键字段 | 索引 |
|---|---|---|---|
| `trip` | 行程表 | trip_name/destination/start_date/end_date/theme_color/status/owner_id | PK(id)、idx_trip_owner(owner_id) |
| `trip_day` | 行程日程表（按天） | trip_id/day_no/trip_date | PK(id)、uk_trip_day(trip_id,day_no) |
| `trip_item` | 日程项表 | day_id/item_name/item_type/start_time/end_time/spot_id/note/sort_order | PK(id)、idx_trip_item_day(day_id)、idx_trip_item_spot(spot_id) |
| `trip_spot` | 景点库表 | spot_name/city/address/lng/lat/rating/intro/image_url | PK(id)、idx_trip_spot_city(city) |
| `trip_member` | 行程成员表 | trip_id/user_id/role | PK(id)、uk_trip_member(trip_id,user_id) |
| `trip_budget` | 预算项表 | trip_id/category/budget_amount/actual_amount | PK(id)、uk_trip_budget(trip_id,category) |

### 9.3 设计要点

- 6 张表均含若依规范字段：`id`(主键)、`create_by`、`create_time`、`update_by`、`update_time`、`remark`。
- 主键统一 `bigint` 自增；`create_by/update_by` varchar(64)；`create_time/update_time` datetime；`remark` varchar(500)。
- 经纬度用 `decimal(10,6)`（T13 高德选点回填）；评分 `decimal(2,1)`；金额 `decimal(10,2)`。
- 时间用 `varchar(10)` 存 HH:mm（方案书约定）；日期用 `date`。
- 业务唯一约束：同一行程 `day_no` 唯一、`(trip_id,user_id)` 唯一、`(trip_id,category)` 唯一。
- 关联列均建普通索引，覆盖「按行程查日程 / 按日程查项 / 按城市查景点」等查询路径。
- `trip_member.role` 使用反引号（`role` 为 MySQL 关键字，避免冲突）。

### 9.4 验收

- `SHOW TABLES`：`trip / trip_day / trip_item / trip_spot / trip_member / trip_budget` 6 张表全部存在。
- 字段注释完整性：6 张表 `information_schema.COLUMNS` 中无注释字段数均为 0。
- 索引：每张表主键 + 上表所列二级/唯一索引齐全。
